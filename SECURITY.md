# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch. Older
releases may not receive fixes so please upgrade to the latest version before
reporting an issue.

## Reporting a vulnerability

Please do **not** open a public issue for a security vulnerability. Use
GitHub's private vulnerability reporting:

<https://github.com/MichaelWiciak/randwallpaper/security/advisories/new>

Please include:

- the affected version and installation method;
- the operating system and Go version;
- a minimal reproduction (command, code, seed, and input files if relevant);
- the impact you believe the issue has.

Reports are handled on a best-effort basis. We will acknowledge valid reports,
keep you updated while a fix is prepared, and credit you in the advisory unless
you prefer to remain anonymous.
